# Tabela comercial — Edifício Residencial Izabel

Página estática da tabela de unidades, publicada para consulta em navegador.

- `tabela/AAAA-MM/index.html` — a tabela da competência
- `robots.txt` e `<meta name="robots">` — página fora de buscadores

Cada competência entra numa pasta própria, para que um endereço antigo nunca mostre valor de
outro mês. A tabela vigente traz a data de validade no topo.

Incorporação registrada sob R.-2/11.701 no 2º Ofício de Registro de Imóveis da Comarca de
Mafra/SC.
